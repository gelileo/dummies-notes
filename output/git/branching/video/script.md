Branching: splitting the history into a second line

## History is a line of linked commits

A project's history is a line of commits, each one a snapshot stamped with an id and linked back to the commit before it.

To try something new, you start a branch: a second line growing straight out of an existing commit.

That new line is a branch, here named feature; it shares every commit up to the split point.

The commit you split from also stays on main, so a single commit ends up with two children.

From here each line adds its own commits, so you can build the feature without touching main.
